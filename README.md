# SortCam+ 1.3.0

- 갤러리 사진 여러 장 가져오기, 분류 선택, 복사본 저장 및 한글·영문·숫자 자동 OCR. 원본 유지.
- 가져오기 진행·완료·중복·실패 안내. 같은 선택 URI 재가져오기 방지. 화면 회전 중 작업 유지. 앱 프로세스가 종료되면 아직 처리하지 않은 사진은 다시 선택해야 합니다.
- 검색어를 공백·쉼표로 구분하고 모두 포함 / 하나라도 포함 선택.
- 오른쪽 아래 원형 전후면 전환 아이콘과 가운데 촬영 버튼.
- 상태 표시줄·화면 잘림·하단 제스처·키보드 영역을 피하는 인셋 적용.
- 기존 앱을 보존하기 위해 `SortCam+` (`com.sortcam.app.next`)로 함께 설치. 이전 앱의 태그·메모는 자동 이전하지 않습니다.
- 개발용 서명은 `test-signing/README.md` 참고.

빌드: Gradle 8.11.1 / JDK 17 / Android API 36. `gradle testDebugUnitTest assembleDebug`.

# SortCam Android MVP v3

SortCam은 **앱을 켜자마자 바로 촬영하고**, 촬영 전에 선택한 분류로 사진과 동영상을 자동 정리한 뒤 나중에 검색해서 바로 열고·공유하고·편집할 수 있게 만든 Android 카메라 앱입니다.

## v3 핵심 변경점

### 1. 실행 즉시 전체 화면 카메라
- 앱 시작 화면이 카메라입니다.
- 별도의 촬영 탭을 먼저 누를 필요가 없습니다.
- 상단의 분류 버튼으로 현재 저장 분류만 빠르게 바꿉니다.
- 전/후면 카메라 전환 버튼을 제공합니다.

### 2. 사진 + 동영상 촬영
- 하단 오른쪽의 `사진 / 동영상` 버튼으로 모드를 전환합니다.
- 사진은 `Pictures/SortCam/<분류>/`에 저장됩니다.
- 동영상은 `Movies/SortCam/<분류>/`에 저장됩니다.
- 동영상 촬영 시 마이크 권한이 있으면 소리도 같이 녹음합니다.

### 3. 자동 미디어 태그
- 사진 촬영 즉시 `#사진` 태그가 자동 추가됩니다.
- 동영상 촬영 즉시 `#동영상` 태그가 자동 추가됩니다.
- 사용자가 태그를 수정해도 해당 자동 태그는 유지됩니다.
- 검색창에 `사진`, `동영상`, `video`, `image` 등을 입력해서도 찾을 수 있습니다.

### 4. 촬영을 방해하지 않는 태그 입력
- 촬영할 때마다 입력 팝업이 강제로 뜨지 않습니다.
- 촬영 즉시 갤러리 + SortCam DB에 저장됩니다.
- 촬영 직후 잠깐 표시되는 `태그 추가`를 누르면 메모와 태그를 입력할 수 있습니다.
- 무시하고 바로 다음 사진/동영상을 계속 촬영할 수도 있습니다.

### 5. 실제 카메라 앱처럼 앨범 진입
- 카메라 화면 좌측 하단에 **가장 최근 사진/동영상 썸네일**이 표시됩니다.
- 썸네일을 누르면 바로 SortCam 앨범이 열립니다.
- 동영상 썸네일에는 `▶` 표시가 붙습니다.

### 6. 갤러리형 3열 앨범
- 저장된 미디어를 3열 썸네일 그리드로 보여줍니다.
- `전체 / 사진 / 동영상` 필터를 제공합니다.
- 검색창에서 분류, 태그, 메모, OCR 글자, 전화번호, 숫자를 통합 검색합니다.

### 7. 사진 OCR 검색
- 사진은 ML Kit OCR로 한글/영문/숫자를 읽습니다.
- `010-1234-5678`이 사진에 있으면 `01012345678`로도 검색할 수 있습니다.
- 계약번호, 송장번호, 제품 시리얼 같은 긴 숫자도 검색 인덱스에 들어갑니다.
- OCR은 촬영 뒤 백그라운드에서 처리되므로 다음 촬영을 막지 않습니다.

### 8. 사진·동영상 활용
앨범에서 썸네일 오른쪽 위 `⋮` 버튼을 누르면:
- 보기
- 공유
- 사진/동영상 편집기 열기
- 태그·메모 수정
- OCR 다시 읽기(사진)
- 다른 분류로 이동
- 원본 + 검색정보 삭제

공유는 Android 시스템 공유창을 사용하므로 카카오톡, 문자, 메일, Quick Share 등 설치된 앱으로 보낼 수 있습니다.

## 프로젝트 열기
1. Android Studio에서 이 폴더를 엽니다.
2. Android SDK 36이 설치되어 있어야 합니다.
3. Gradle Sync를 실행합니다.
4. Android 10(API 29) 이상 기기에서 실행합니다.

## APK 빌드
Android Studio 메뉴:
`Build > Build APK(s)`

또는 Gradle Wrapper 준비 후:
`./gradlew assembleDebug`

결과 파일 예시:
`app/build/outputs/apk/debug/app-debug.apk`

## 현재 구조
- CameraX ImageCapture: 사진
- CameraX VideoCapture + Recorder: 동영상/오디오
- MediaStore: 휴대폰 갤러리 원본 저장
- SQLite: 분류/태그/메모/OCR/미디어종류 검색정보
- ML Kit Text Recognition: 사진 OCR

## 추후 AI 확장
OpenAI 등 서버 기반 비전 분석을 추가하면 사진에 보이는 물건/문서/상황을 자동 태그화할 수 있습니다.
동영상은 대표 프레임 추출 + 음성 전사 + 장면 요약을 조합해 `회의`, `반려동물`, `여행`, `제품명` 같은 내용 검색으로 확장할 수 있습니다.
API 키는 APK에 직접 넣지 않고 백엔드 서버에서 관리하는 구조가 권장됩니다.

## GitHub Actions 자동 APK 빌드
프로젝트에 `.github/workflows/android-build.yml`이 포함되어 있습니다.
GitHub 저장소의 기본 브랜치에 프로젝트를 올리면 자동으로 Debug APK를 빌드하고 `SortCam-debug-apk` 아티팩트로 업로드합니다.
또는 GitHub의 `Actions > Build SortCam APK > Run workflow`에서 수동 실행할 수 있습니다.
